What's coming

Built for two kinds of users

Search it directly

Browse and filter Luxeon's verified datasets in the browser — demographics, prices, competitor and location data, and more — without commissioning a custom project.

Pull it through the API

Query datasets programmatically and bring the numbers straight into your own dashboards, models or products.

Trust the source

Every dataset ships with a source log, a refresh date and a documented coverage-gap register — the same standard Luxeon applies to client work.

API access

Simple, documented endpoints

Every dataset in the browser search will also be reachable through a REST API, with the same fields, filters and source notes — so the database and your own systems stay in sync.

// example request
GET /v1/datasets/ghana-market-prices?region=greater-accra
Authorization: Bearer YOUR_API_KEY

// example response
{
  "dataset": "ghana-market-prices",
  "refreshed": "2026-08-01",
  "rows": 10780,
  "source": "MoFA, GSS"
}
